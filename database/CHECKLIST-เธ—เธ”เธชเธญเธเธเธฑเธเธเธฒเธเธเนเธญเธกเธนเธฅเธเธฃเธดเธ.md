# เช็กลิสต์ทดสอบกับฐานข้อมูลจริง (Supabase)

ทำครั้งเดียวหลังติดตั้งไฟล์ชุดใหม่ ใช้เวลาประมาณ 30–45 นาที
แนะนำให้ทำบนโปรเจกต์ **DEV** ก่อน ผ่านแล้วค่อยทำซ้ำบน **MAIN**

เตรียมไว้:
- บัญชีทดสอบ 4 บทบาท: พนักงาน (staff), หัวหน้างาน (supervisor), ฝ่ายบัญชี (accounting), แอดมิน (admin)
- มือถือ 1 เครื่อง + คอมพิวเตอร์ 1 เครื่อง
- QR แผนกและ QR เครื่องอย่างน้อยอย่างละ 1 อัน (พิมพ์จากหน้าแอดมิน)
- ใช้ **วันที่ของเดือนเก่าที่ไม่มีข้อมูลจริง** ตอนทดสอบปิดงวด (เช่น เดือนที่แล้วบน DEV)

## 1. พนักงานหน้างาน (มือถือ)

- [ ] เปิดแอปครั้งแรก → หน้าเปิดแอปเล่นแอนิเมชันครบ แล้วเข้า Login
- [ ] สแกน QR แผนก → เลือกชื่อ → เข้าฟอร์ม
- [ ] ช่อง "เครื่องจักร" แสดงเครื่องของแผนกนั้นครบ (ไม่ใช่รายการสำรอง)
- [ ] ช่อง "ประเภทปัญหา" แสดงปัญหาของแผนกนั้นครบ
- [ ] เปิด DevTools (หรือดูบนคอม) → **ไม่มี error 400** ตอนโหลดฟอร์ม
- [ ] บันทึก 1 รายการ (2 ปัญหา) → ขึ้น "บันทึกข้อมูลเรียบร้อยแล้ว"
- [ ] บันทึกซ้ำรายการเดิม → ขึ้นเตือน "พบข้อมูลซ้ำ"

### 1.1 บันทึกตอนเน็ตหลุด
- [ ] เปิดฟอร์มค้างไว้ → ปิด Wi-Fi/เน็ตมือถือ → กรอกแล้วกดบันทึก
- [ ] ขึ้นถาม "ตอนนี้ไม่มีอินเทอร์เน็ต … บันทึกไว้ในเครื่องนี้ก่อน" → ตกลง
- [ ] มุมล่างขึ้นป้าย "รอส่ง 1 รายการ · ไม่มีอินเทอร์เน็ต"
- [ ] เปิดเน็ตกลับ → ภายในไม่กี่วินาทีขึ้น "ส่งข้อมูลที่บันทึกไว้ตอนออฟไลน์แล้ว 1 รายการ" และป้ายหายไป
- [ ] หัวหน้างานเห็นรายการนั้น **1 รายการ** (ไม่ซ้ำ)
- [ ] ทดสอบซ้ำแบบ: ปิดเน็ต → บันทึก → **ปิดแอป** → เปิดเน็ต → เปิดหน้า Login ใหม่ → ระบบส่งให้เอง

## 2. หัวหน้างาน

- [ ] เข้าหน้า "ตรวจสอบรายวัน" → ถ้ามีวันก่อนหน้าที่ยังไม่ส่งบัญชี จะมีแถบสีเหลือง "ยังไม่ได้ส่งบัญชี n วัน"
- [ ] กดวันที่ในแถบ → เปิดวันนั้นทันที
- [ ] ตรวจ/แก้ไข → ยืนยันสถานะเครื่อง → กด "ส่งข้อมูลประจำวันให้บัญชี" → สำเร็จ
- [ ] หลังส่งครบ แถบเตือนของวันนั้นหายไป
- [ ] แถบเมนูล่างมี 5 ปุ่ม ปุ่ม "ประวัติ" เลื่อนไปที่รายการที่ส่งแล้ว

## 3. ฝ่ายบัญชี (คอมพิวเตอร์)

- [ ] เห็นรายการที่หัวหน้าส่งมา, การ์ด "รอบัญชีตรวจ" นับถูก
- [ ] กรอกน้ำหนักผลิต 2–3 แถว (กด Enter ไปช่องถัดไป) → ช่องเป็นกรอบส้ม → ปุ่ม "บันทึกทั้งหมด (n)" โผล่
- [ ] รอเกิน 30 วินาที (รีเฟรชอัตโนมัติ) → ตัวเลขที่พิมพ์ **ยังอยู่**
- [ ] กด "บันทึกทั้งหมด" → สำเร็จ สถานะเป็น "บัญชีตรวจแล้ว"
- [ ] กด "แก้ไข" แถวที่บันทึกแล้ว → เปลี่ยนตัวเลข → บันทึก
- [ ] กดลูกศรเปิดรายละเอียดแถวนั้น → "ประวัติการแก้น้ำหนักผลิต" แสดง 2 บรรทัด (ว่าง → ค่าแรก, ค่าแรก → ค่าใหม่) พร้อมชื่อผู้แก้
- [ ] ปุ่ม "ส่งออก Excel" → ได้ไฟล์ .xlsx มี 4 แผ่น (สรุปแผนก / รายการ / รายการปัญหา / ข้อมูลรายงาน) ตัวเลขตรงกับหน้าจอ
- [ ] เมนู "Dashboard ของเสีย" → สลับ รายวัน/สัปดาห์/เดือน/ปี ได้, กดแท่งกราฟแล้วการ์ดเปลี่ยนตาม

### 3.1 ปิดงวดบัญชี (ใช้เดือนทดสอบ)
- [ ] เลือกเดือนทดสอบในตัวกรอง → แถบ "งวด … ยังเปิดอยู่" → กด "ปิดงวดเดือนนี้" → ยืนยัน
- [ ] แถบเปลี่ยนเป็น "ปิดบัญชีแล้ว โดย …" ทุกแถวของเดือนนั้นขึ้น "ปิดงวดแล้ว" แก้ไม่ได้
- [ ] **หัวหน้างาน** ลองแก้/ลบรายการของเดือนนั้น → ทำไม่ได้ ขึ้นข้อความ "งวด … ปิดบัญชีแล้ว"
- [ ] **พนักงาน** ลองบันทึกโดยตั้งวันที่เป็นเดือนนั้น → ขึ้น "เดือนนี้ฝ่ายบัญชีปิดงวดแล้ว"
- [ ] **หัวหน้างาน** พยายามเปิดงวดเอง (ไม่มีปุ่ม) — ถ้าลองผ่าน SQL/REST ต้องถูกปฏิเสธ
- [ ] ฝ่ายบัญชีกด "เปิดงวดอีกครั้ง" → แก้ไขได้ตามปกติ
- [ ] เช็ก: `select * from accounting_period_lock_events order by at desc limit 5;` → มีบันทึก lock / unlock พร้อมชื่อ

## 4. แอดมิน

- [ ] Dashboard แสดงสถานะ 4 แบบ (รอหัวหน้าตรวจ / รอบัญชีตรวจ / บัญชีตรวจแล้ว / ยกเลิก) ถูกต้อง
- [ ] เปิด "เพิ่ม User" → ติ๊กแผนก → รอเกิน 30 วินาที → ช่องที่ติ๊กยังอยู่ → บันทึกสำเร็จ และ login ได้

- [ ] ส่งออก CSV รายงาน → คอลัมน์น้ำหนักมีตัวเลขจริง (ไม่เป็น 0)
