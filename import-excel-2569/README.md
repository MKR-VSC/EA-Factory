## ข้อควรรู้

- **กะ**: Excel ส่วนใหญ่เป็น "เช้า/ดึก" (รวมกะ) → รายงานประจำวันนับในช่อง "รวมทั้งสิ้น" แต่ไม่แยกช่องกะเช้า/กะบ่าย-ดึก
  สะกดผิดแก้ให้แล้ว (เข้า → เช้า, เช้า. → เช้า) · ไม่ระบุกะ → "ไม่ระบุกะ"
- **ประเภทของเสีย**: ใส่ตามที่ตั้งไว้ของอาการตอนนำเข้า (ครั้งแรกทุกอาการ = การผลิต)
  หลังเจ้านายกำหนดประเภทในเมนู "อาการเสีย & ประเภท" แล้ว รันคำสั่งท้ายไฟล์ `12-loss-types.sql`
  (ส่วน "ใช้ครั้งเดียวตอนตั้งระบบ") เพื่อปรับข้อมูลที่นำเข้าให้ใช้ประเภทใหม่
- **สถานะ**: มียอดผลิต → "บัญชีตรวจแล้ว" · ไม่มียอดผลิต → "รอบัญชีตรวจ" (จะเห็นในหน้าบัญชี)
- **เครื่องรีไซเคิล**: แถว "LD-ก้อนแข็ง / HD-ก้อนแข็ง" = ของเสียของกะนั้น + น้ำหนักผลิตของเม็ดชนิดนั้น
  → ของเสียเป็นรายการ "LD-ก้อนแข็ง" ฯลฯ · น้ำหนักผลิตลงยอดผลิตแยกกะ ชนิดเม็ด LD / HD (ไฟล์ 13)
  แถว "เปลี่ยนตะแกรง" (จำนวนครั้งในช่องหมายเหตุ) ไม่ได้นำเข้า เพราะไม่ใช่น้ำหนัก และระบบยังไม่มีช่องเก็บ
- งวดที่ปิดบัญชีไว้แล้ว (ไฟล์ 09) จะนำเข้าไม่ได้ — เปิดงวดก่อน
- ข้อมูลที่นำเข้ามีผู้บันทึก "นำเข้า Excel 2569" และหมายเหตุ `IMPORT:EXCEL2569`
