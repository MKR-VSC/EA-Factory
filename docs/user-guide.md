# คู่มือการใช้งาน EA Factory

## 1. ภาพรวมระบบ

EA Factory เป็นระบบบันทึกและติดตามข้อมูลของเสียจากการผลิต โดยมีขั้นตอนหลักดังนี้

1. ผู้ปฏิบัติงานบันทึกปัญหาที่พบจากหน้างาน
2. หัวหน้างานตรวจสอบรายการของเสียประจำวัน
3. ฝ่ายบัญชีตรวจสอบและจัดการข้อมูลที่เกี่ยวข้องกับการสรุปผล
4. ผู้บริหารดูภาพรวม สถิติ และแนวโน้มของเสีย
5. ผู้ดูแลระบบจัดการผู้ใช้งาน ข้อมูลตั้งต้น และ QR Code

ระบบใช้สิทธิ์ตาม Role และแผนกของผู้ใช้งาน ข้อมูลที่เห็นหรือแก้ไขได้จึงอาจแตกต่างกัน

## 2. การเข้าสู่ระบบ

### เข้าด้วย Username และ Password

1. เปิดหน้า `login.html`
2. กรอก Username
3. กรอก Password
4. เลือก **จำ Username ไว้ในเครื่องนี้** หากเป็นเครื่องส่วนตัว
5. กด **เข้าสู่ระบบ**

ระบบจะพาไปยังหน้าหลักตาม Role ของผู้ใช้งานโดยอัตโนมัติ

### เข้าด้วย QR Code

1. กด **สแกน QR Code** ที่หน้า Login
2. อนุญาตให้เว็บไซต์ใช้กล้อง
3. สแกน QR ของแผนกหรือเครื่องจักร
4. ตรวจสอบชื่อแผนกและเครื่องจักรที่แสดง
5. เลือกชื่อผู้บันทึก
6. กด **เข้าสู่หน้าบันทึกข้อมูล**

> QR ของเครื่องจักรจะกำหนดแผนกและเครื่องจักรให้ล่วงหน้า ส่วน QR ของแผนกจะกำหนดเฉพาะแผนก

## 3. การบันทึกข้อมูลของเสียจากหน้างาน

ใช้สำหรับพนักงานหรือหัวหน้างานที่ต้องบันทึกปัญหาการผลิต

1. ตรวจสอบ **แผนกปัจจุบัน** ให้ถูกต้องก่อนกรอกข้อมูล
2. ระบุวันและเวลาที่เกิดเหตุจริง
3. เลือกกะการทำงาน
4. เลือกเครื่องจักรหรือไลน์การผลิต
5. ในส่วน **รายการปัญหาที่พบ** เลือกปัญหาอย่างน้อย 1 รายการ
6. กรอกน้ำหนักของเสียแยกตามปัญหา
7. กด **เพิ่มปัญหา** หากพบมากกว่า 1 ปัญหาในเหตุการณ์เดียว
8. ตรวจสอบ **น้ำหนักของเสียรวม**
9. หากเลือกปัญหา **อื่นๆ** ให้ระบุรายละเอียดเพิ่มเติมแล้วกด **บันทึกรายละเอียด**
10. กด **บันทึกข้อมูล** และรอจนระบบแจ้งว่าบันทึกสำเร็จ

ข้อควรระวัง:

- ข้อมูลที่บันทึกจะอ้างอิงแผนกจาก Login หรือ QR จึงควรตรวจสอบแผนกก่อนทุกครั้ง
- น้ำหนักของเสียรวมคำนวณจากรายการปัญหาทั้งหมดในฟอร์ม
- อย่ากดปุ่มบันทึกซ้ำระหว่างที่ระบบกำลังแสดงข้อความ **กำลังบันทึกข้อมูล...**
- ใช้ **ล้างข้อมูล** เมื่อต้องการเริ่มกรอกฟอร์มใหม่
- กด **ออกจากระบบ** เมื่อใช้งานเสร็จ โดยเฉพาะเครื่องที่ใช้ร่วมกัน

## 4. หน้าตาม Role

| Role | หน้าที่หลัก | หน้าเริ่มต้น |
| --- | --- | --- |
| `staff` พนักงาน | บันทึกข้อมูลของเสียของแผนก | ฟอร์มบันทึกข้อมูล |
| `supervisor` หัวหน้างาน | ตรวจสอบรายการและอนุมัติ/ไม่ผ่านตามสิทธิ์ | ตรวจสอบข้อมูลรายวัน |
| `accounting` ฝ่ายบัญชี | ตรวจสอบข้อมูลของเสียและข้อมูลสำหรับงานบัญชี | แผงบัญชี |
| `management` ผู้บริหาร | ดูสรุปและสถิติของเสียทั้งโรงงาน | Dashboard |
| `admin` ผู้ดูแลระบบ | จัดการทุกส่วนของระบบตามสิทธิ์ | Admin Panel |

## 5. การตรวจสอบข้อมูลรายวันสำหรับหัวหน้างาน

1. เปิดหน้า **ตรวจสอบข้อมูลรายวัน**
2. เลือกหรือกรองวันที่และแผนกที่ต้องการตรวจสอบ
3. ตรวจสอบรายการรายงานของเสียและรายละเอียดปัญหา
4. ตรวจสอบน้ำหนัก เครื่องจักร กะ และชื่อผู้บันทึก
5. เลือกดำเนินการกับรายการตามที่ระบบอนุญาต เช่น ตรวจสอบแล้วหรือไม่ผ่าน
6. ตรวจสอบรายการที่บันทึกลงระบบแล้วอีกครั้ง

หัวหน้างานจะเห็นข้อมูลตามแผนกที่รับผิดชอบ หากดูแลหลายแผนก ระบบจะแสดงเฉพาะแผนกที่ได้รับมอบหมาย

## 6. Dashboard สำหรับผู้บริหาร

1. เลือกเดือนที่ต้องการดู
2. เลือกแผนก หรือเลือก **ทุกแผนกผลิต**
3. กด **ค้นหา**
4. อ่านสรุปผลิตรวม ของเสียรวม และ `% Waste`
5. ตรวจสอบแผนกหรือเครื่องจักรที่มีของเสียสูง
6. ดูแนวโน้มของเสียรายวัน และหัวข้อปัญหาที่พบบ่อย
7. กด **โหลดใหม่** เมื่อต้องการดึงข้อมูลล่าสุด
8. กด **Export CSV** หากต้องการนำข้อมูลไปวิเคราะห์ต่อ

## 7. แผงบัญชี

1. เปิดหน้า **แผงควบคุมข้อมูลของเสีย - บัญชี**
2. ค้นหาด้วยเครื่องจักร ปัญหา หรือผู้บันทึก
3. ตรวจสอบรายการของเสียจากหน้างาน
4. ตรวจสอบน้ำหนักและรายละเอียดให้ตรงกับเอกสารหรือข้อมูลที่เกี่ยวข้อง
5. ดำเนินการแก้ไขหรือยืนยันข้อมูลตามสิทธิ์ของบัญชี

## 8. Admin Panel

เฉพาะ `admin` เท่านั้นที่ควรจัดการข้อมูลส่วนนี้

### Dashboard

- ดูจำนวนรายการทั้งหมด รายการที่รอตรวจสอบ และน้ำหนักของเสียรวม
- ตรวจสอบสถานะการเชื่อมต่อ Supabase
- ค้นหาและกรองรายการตามสถานะ เช่น รอตรวจสอบ ตรวจสอบแล้ว หรือไม่ผ่าน

### Master Data

Master Data คือข้อมูลตั้งต้นที่ผู้ใช้งานเลือกในฟอร์ม ควรจัดการให้เรียบร้อยก่อนเริ่มใช้งานจริง

1. เพิ่มหรือแก้ไข **แผนก** ด้วยรหัสและชื่อแผนก
2. เพิ่มหรือแก้ไข **กะการทำงาน** พร้อมช่วงเวลา
3. เลือกแผนกก่อนจัดการเครื่องจักรและอาการเสีย
4. เพิ่ม **เครื่องจักร** ให้ตรงกับแผนก
5. เพิ่ม **หัวข้ออาการเสีย** ที่ต้องการให้พนักงานเลือก
6. ปิดใช้งานข้อมูลที่ไม่ใช้แล้ว แทนการลบ หากต้องการเก็บประวัติเดิม

### Users / Roles

1. กด **เพิ่ม User ใหม่**
2. กรอก Username, Password และชื่อแสดงผล
3. เลือก Role
4. เลือกแผนกหลัก
5. หากเป็น Supervisor ให้เลือกแผนกที่รับผิดชอบได้มากกว่า 1 แผนก
6. กด **บันทึก User**
7. ใช้ตัวกรอง Role และสถานะเพื่อค้นหาและตรวจสอบผู้ใช้งาน

ควรตั้งสถานะเป็น `inactive` สำหรับผู้ที่ไม่ได้ใช้งานแล้ว และไม่ควรใช้บัญชีร่วมกันหลายคน เพราะระบบเก็บชื่อผู้บันทึกและประวัติการใช้งาน

### QR แผนก และ QR รายเครื่อง

- **QR แผนก**: สร้างลิงก์หรือ QR สำหรับเปิดฟอร์มของแผนก
- **QR รายเครื่อง**: เลือกแผนก แล้วสร้าง QR ให้เครื่องจักรแต่ละเครื่อง
- ทดสอบสแกน QR หลังสร้างทุกครั้ง และตรวจสอบว่าแผนก/เครื่องจักรตรงกับป้ายหน้างาน
- หากเปลี่ยนชื่อหรือรหัสแผนก ควรตรวจสอบ QR ที่พิมพ์ใช้งานอยู่ด้วย

### System Logs และการใช้งานระบบ

ใช้ตรวจสอบเหตุการณ์และประวัติการทำงาน เช่น การเข้าสู่ระบบ การบันทึกข้อมูล และการเปลี่ยนแปลงข้อมูลสำคัญ เพื่อช่วยติดตามปัญหาและตรวจสอบย้อนหลัง

## 9. การออกจากระบบ

กด **ออกจากระบบ** จากหน้าที่กำลังใช้งาน แล้วตรวจสอบว่าระบบกลับไปยังหน้า Login หากเป็นเครื่องส่วนกลางควรออกจากระบบทุกครั้งหลังใช้งาน

## 10. แนวทางแก้ปัญหาเบื้องต้น

### ไม่พบแผนก เครื่องจักร กะ หรืออาการเสีย

แจ้ง Admin ให้ตรวจสอบ Master Data และสถานะการเปิดใช้งานของข้อมูลนั้น

### บันทึกข้อมูลไม่สำเร็จ

1. ตรวจสอบการเชื่อมต่ออินเทอร์เน็ตจากสถานะ `ONLINE`
2. ตรวจสอบว่ากรอกช่องที่มีเครื่องหมาย `*` ครบ
3. ตรวจสอบน้ำหนักของเสียและรายการปัญหา
4. โหลดหน้าใหม่แล้วลองอีกครั้งเมื่อแน่ใจว่ายังไม่มีรายการถูกบันทึก
5. หากยังไม่สำเร็จ ให้แจ้ง Admin พร้อมวันเวลา แผนก เครื่องจักร และข้อความแจ้งเตือน

### QR เปิดผิดแผนกหรือผิดเครื่อง

หยุดกรอกข้อมูลและแจ้ง Admin ให้สร้างหรือตรวจสอบ QR ใหม่ อย่าแก้ด้วยการเลือกเครื่องจักรอื่นเพื่อบันทึกแทน

### เข้าสู่ระบบไม่ได้

ตรวจสอบ Username/Password และสถานะบัญชี หากบัญชีถูกปิดใช้งาน ให้ติดต่อ Admin

## 11. หลักปฏิบัติในการใช้งาน

- ตรวจสอบแผนก เครื่องจักร วันเวลา และกะก่อนบันทึกทุกครั้ง
- บันทึกข้อมูลใกล้เวลาที่พบปัญหามากที่สุด
- กรอกรายละเอียด **อื่นๆ** ให้ชัดเจน เพื่อใช้วิเคราะห์สาเหตุภายหลัง
- ไม่ใช้ Username ของผู้อื่น
- ไม่เปิดเผย Password และไม่เลือกจำ Username บนเครื่องสาธารณะ
- ตรวจสอบผลการบันทึกให้สำเร็จก่อนปิดหน้าเว็บ
